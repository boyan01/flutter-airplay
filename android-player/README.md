# Flutter AirPlay Android

Playable Android host for this project: pinned UxPlay receive core, Flutter
embedded H.264 video, MediaCodec/FFmpeg audio decoding, and Oboe output.

See [Android player build and use](../docs/ANDROID_PLAYER.md),
[NOTICE](NOTICE), and [pinned playback dependencies](dependencies.lock.json).

Keep the app open on the same Wi-Fi as the iPhone, then choose
**Flutter AirPlay Android** in iPhone Control Center → Screen Mirroring.
